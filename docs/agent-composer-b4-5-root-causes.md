## Method and shared observations

Each row below was checked against the synthetic fixture, fixed policy action, `CommunicationProblem`-projected evidence, `CommunicationAssessment`, `SkillSelectionResult`, compiled `SkillPlan`, legacy `CommunicationPlan`, exact guidance arrays passed to Composer, primary and all alternatives, deterministic result, and the human B4 judgment. The provider-facing core prompt, model, output schema and settings were common to both arms. The B4 evaluation-only adapter copied the new plan's principle/avoid text verbatim and in order; it did **not** drop a reference, reorder text on its own, or attach action/control fields. It also flattened the plan's skill/evidence references and priority context into the legacy guidance shape, but no B4 row proves that flattening alone caused a failure. The guard checked every returned candidate but reported only a package-level `INVALID_RESPONSE`, not a rule code.

`SOURCE_DRAFT`, `VISIBLE_MESSAGE`, language and context-tag evidence are bounded structural references, not evidence that an unstated status or commitment is true. Unknown identity/relationship/goal markers remain unknown. The detailed candidate text stays in the original ignored B4 worksheet; this audit quotes only small synthetic fragments needed to explain a finding. A row's primary layer identifies the strongest supported explanation, not a causal claim that one stochastic generation proves a systematic effect. No Skill selector/compiler change follows from a single quality preference alone.

## Layer count, adapter audit and remediation boundary

Primary layers across 15 rows: `COMPOSER_PROMPT_OR_GENERATION` **10**, `SHARED_SYSTEM_LIMITATION` **4**, `SELECTION` **1**; all other allowed primary layers **0**. Secondary guard gaps are identified in eight rows (four status, Korean commitment, simple-planning user state, ordinary ask modal, ordinary appreciation). No row demonstrates a primary assessment, SkillPlan compilation or compatibility-adapter fault. The single selection row is a quality hypothesis, not permission to alter the B3.5-signed selector without stronger evidence.

The compatibility adapter flattens references and priority context because `CommunicationGuidance` has only ordered principles/avoidances; it does not truncate, duplicate or reword them. The greatest observable difference is selected-skill order/content upstream, not adapter distortion. `missed-commitment` already places timing first in new guidance, yet one alternative drops tomorrow; adding another generic timing principle would be speculative. Narrow B4.5 remediation should target candidate-level meaning/factual constraints and the specific guard gaps, while leaving assessment/selection/compiler untouched unless new deterministic evidence contradicts this audit.

`FIXTURE-TONE-05` is not among the 15: the original `sparse-nicer` puts an instruction in the compose draft rather than an Agent-owned instruction field. Its root-cause layer is `FIXTURE`; it stays outside quality tallies until a valid test-only seam or production producer exists.
